# Site — Dra. Amanda Nelvo

Versão estática e responsiva do site profissional, pronta para publicação.

## Antes de publicar

No arquivo `index.html`, substitua o endereço provisório do Instagram (`https://www.instagram.com/`) pelo perfil correto. O WhatsApp já está configurado como `(21) 97377-5036`.

## Publicação rápida

### Netlify

1. Acesse `https://app.netlify.com/drop`.
2. Arraste a pasta `dra-amanda-site` ou o arquivo ZIP.
3. O endereço público será criado automaticamente.

### Hostinger

1. Abra o Gerenciador de Arquivos da hospedagem.
2. Entre na pasta `public_html`.
3. Envie o conteúdo desta pasta, mantendo `assets`, `index.html`, `styles.css` e `script.js` juntos.

### GitHub Pages

1. Crie um repositório e envie todos os arquivos.
2. Em Settings → Pages, selecione a branch principal e a pasta raiz.

Não é necessário instalar dependências ou executar comandos de compilação.
